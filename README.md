# ديلي تكنولوجي

موقع شركة **ديلي تكنولوجي** (Deli Technology): برمجة، تصميم، وتسويق رقمي من فلسطين.

البيانات مأخوذة من الموقع العام للشركة: الرسالة، الرؤية، الخدمات، الأرقام (12 نظامًا، 260 موقعًا، 150 تصميمًا، 250 تطبيقًا)، المشاريع المنشورة، وبيانات التواصل.

- العربية: `/ar`
- English: `/en`

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000). الصفحة الرئيسية تحوّل إلى `/ar`.
